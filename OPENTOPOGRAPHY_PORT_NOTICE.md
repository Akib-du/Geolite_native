# OpenTopography DEM Downloader port

The native Android implementation in `app/src/main/java/com/akib/geolite/OpenTopographyDemDownloader.kt` is a port of the download workflow from **OpenTopography DEM Downloader** by **Kyaw Naing Win**.

- Original QGIS plugin: https://plugins.qgis.org/plugins/OpenTopography-DEM-Downloader/
- Original source: https://github.com/knwin/OpenTopography-DEM-Downloader-qgis-plugin
- The original plugin metadata declares the plugin as GPL-2.0-or-later. The port retains attribution and is intended to be distributed under GPL-2.0-or-later.
- DEM data and API access are provided by OpenTopography and remain subject to OpenTopography's terms, dataset conditions and API limits.
